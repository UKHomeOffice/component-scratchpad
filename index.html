Scratchpad


Scratchpad is an open-source tool with which you can quickly create html content for prototypes and other non-live pages, based on gov.uk components. It's a standalone html file and can run in any modern browser.

View Scratchpad in a browser

Download it and other files from the github repository
 

How it works

Instead of writing html code, describe each component using (relatively) plain language, called scratchdown.

Each new component description must start with ##. The format is:
##component_name | Label or text | Further options

Returns are permitted,allowing multiple paragraphs of content e.g.
##p | This is part of a simple paragraph of text.

And so is this.

Components with repeating elements, like the summary list, table or check answers components work like this:
##component_name | Label or text | column value:column value:column value

Provide basic layout using Row and Column.
Define column width using the format 'Column|width' e.g. Column|100 will be full width, Column|50 will be 50%.

You can preview your page within Scratchpad, including a full-screen mode.

Once you're happy with the results, use the controls to copy the html to the clipboard, then add it to your prototype.

Using Scratchpad

Scratchpad was created by Ian Smith, a Senior Interaction Designer with the Home Office. It is open source, so please take a copy and change it to fit your needs. It is updated occasionally, but there is no official support!

Adding components from other libraries is fairly straightforward (the only requirement is that they have a permanently available .css file for all styles).
 

Not using Scratchpad

Scratchpad was created as a tool to help with User Centred Design during Discovery and Alpha phases of projects, and should not be used for any live service.
